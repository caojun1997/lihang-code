# PDF解析系统 - 前端交互设计方案

## 一、设计愿景

打造一款**简洁高效**的PDF解析工具，让用户能够：
- 拖拽上传PDF文件
- 实时预览解析结果
- 一键复制或下载Markdown/TXT格式
- 批量处理多个文件
- 追踪处理进度

## 二、设计风格

### 视觉语言
- **风格**：现代简约、专业高效
- **主色调**：#2563EB（蓝色）
- **辅助色**：#10B981（绿色，成功）、#F59E0B（橙色，警告）、#EF4444（红色，错误）
- **背景色**：#F8FAFC（浅灰白）
- **卡片色**：#FFFFFF
- **文字色**：#1E293B（主文字）、#64748B（次要文字）

### 布局设计
- **顶部导航**：Logo + 标题 + 主题切换
- **主内容区**：
  - 左侧：文件上传区 + 文件列表
  - 右侧：预览区 + 操作按钮
- **底部状态栏**：处理进度 + 统计信息

## 四、功能模块设计

### 4.1 文件上传模块

| 功能 | 描述 |
|------|------|
| 拖拽上传 | 支持拖拽多个文件到上传区域 |
| 点击选择 | 支持点击按钮选择本地文件 |
| 粘贴上传 | 支持 Ctrl+V 粘贴PDF文件 |
| 格式校验 | 自动校验文件类型和大小 |
| 进度显示 | 显示上传进度百分比 |
| 预览生成 | 上传完成后自动生成缩略图预览 |

### 4.2 解析配置模块

| 功能 | 描述 |
|------|------|
| 输出格式选择 | Markdown / TXT / JSON |
| 解析模式 | 自动 / 文本提取 / OCR |
| 表格处理 | 保留表格结构 / 转换为文本 |
| 公式处理 | 保留LaTeX格式 |
| 图片处理 | 提取图片并保留引用 |

### 4.3 预览模块

| 功能 | 描述 |
|------|------|
| 分页预览 | 支持逐页查看解析结果 |
| 滚动同步 | 滚动时高亮对应区域 |
| 搜索 | 在解析结果中搜索关键词 |
| 高亮 | 搜索关键词高亮显示 |
| 复制段落 | 点击复制指定段落 |
| 展开/折叠 | 支持长标题的展开/折叠 |

### 4.4 文件管理模块

| 功能 | 描述 |
|------|------|
| 任务列表 | 显示所有解析任务及状态 |
| 状态筛选 | 按状态筛选任务 |
| 批量下载 | 支持批量下载结果文件 |
| 结果对比 | 支持多个结果对比查看 |
| 历史记录 | 保留解析历史（7天） |

### 4.5 导出模块

| 功能 | 描述 |
|------|------|
| 复制全部 | 一键复制所有解析结果 |
| 下载Markdown | 下载.md格式文件 |
| 下载TXT | 下载.txt格式文件 |
| 下载JSON | 下载.json格式文件（包含元数据） |
| 打包下载 | 批量下载所有结果 |

## 五、状态设计

### 5.1 任务状态

| 状态 | 标识 | 说明 |
|------|------|------|
| 等待中 | ⏳ 灰色 | 队列中等待处理 |
| 上传中 | 📤 蓝色 | 正在上传文件 |
| 解析中 | ⚙️ 蓝色 | 正在解析内容 |
| 已完成 | ✅ 绿色 | 解析成功 |
| 部分失败 | ⚠️ 橙色 | 部分页面解析失败 |
| 失败 | ❌ 红色 | 解析失败 |
| 已取消 | 🚫 灰色 | 用户取消 |

## 七、动画和过渡

| 场景 | 动画效果 |
|------|---------|
| 文件拖入 | 边框变为蓝色虚线 + 放大图标 |
| 上传成功 | 缩略图淡入 + 震动反馈 |
| 解析开始 | 卡片展开 + 进度条动画 |
| 解析完成 | 绿色对勾 + 轻微弹跳 |
| 复制成功 | 按钮变色 + 提示文字 |
| 删除文件 | 滑出 + 淡出 |

## 八、错误处理

| 错误类型 | 提示信息 | 解决方案 |
|---------|---------|---------|
| 文件过大 | "文件超过50MB限制" | 提示分割文件或压缩 |
| 格式错误 | "仅支持PDF、DOC等格式" | 显示支持格式列表 |
| 解析失败 | "解析失败，请重试" | 显示重试按钮 |
| 网络错误 | "网络连接失败" | 显示重连按钮 |
| 存储满 | "存储空间不足" | 提示清理历史记录 |

## 九、技术实现方案

### 9.1 前端技术栈
- **框架**：Vue 3 + TypeScript
- **UI组件**：shadcn/ui
- **状态管理**：Pinia
- **HTTP客户端**：Axios
- **拖拽上传**：vue-dropzone
- **Markdown渲染**：marked + highlight.js
- **主题切换**：CSS Variables

### 9.3 API接口设计

| 接口 | 方法 | 描述 |
|------|------|------|
| /api/v1/tasks | POST | 创建解析任务 |
| /api/v1/tasks | GET | 获取任务列表 |
| /api/v1/tasks/:id | GET | 获取任务详情 |
| /api/v1/tasks/:id/status | GET | 获取任务状态 |
| /api/v1/tasks/:id/result | GET | 获取解析结果 |
| /api/v1/tasks/:id/download | GET | 下载结果文件 |
| /api/v1/tasks/:id | DELETE | 删除任务 |
